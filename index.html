Questions, Answered

Do I need to know how to code?

No. You get an editable site and plain instructions. Most changes — text, photos, prices — you can do yourself.

How much does it cost?

R1,500 to set up, then R450 per month. Hosting on GitHub Pages is free, so there's no server bill on top.

Can I use my own domain?

Yes. If you already own a domain (or want one), I'll point it at the site. If not, the free github.io address works fine.

How long does it take?

Most sites are live within 1–2 weeks, depending on how ready your content and photos are.

What if I need changes later?

Message me anytime. Small edits are quick, and you're never locked out of your own files.
